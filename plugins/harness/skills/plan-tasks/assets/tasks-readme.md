## 이슈 전 점검

- [ ] 대상 저장소가 있다(없으면 카드만 유지)
- [ ] 의존 카드가 먼저 `issued` 다
- [ ] 막는 결정이 `complete` 다
- [ ] 이슈 초안이 대상 저장소 `.claude/github-issue.yml` 의 제목 형식·절 구조를 따른다
- [ ] 완료 조건과 검증 명령이 있다
